# 박준서 - 게임 QA 포트폴리오

게임 QA 테스터 취업을 목표로 하는 박준서의 포트폴리오 사이트입니다.
현재는 게이머·웹 개발 중심의 사이트이며, 게임 QA 직무에 맞는 사이트로 개편하고 있습니다.

### 자격 및 수상
- **ISTQB CTFL v4.0** 합격
- **평택시 청년창업지원센터 창업경진대회 동상** (2023)
- **일본어**: 일본어로 게임 코칭 수행

| 게임 | 최고 티어 / 성과 |

| 리그 오브 레전드 | 마스터 |
| TFT | 챌린저 |

| 섀도우버스 | 상위 랭크 |

### 대회 기획·중계·방송
- 평택시고등학교 최강자전 제2회 기획팀, 제3회 기획팀장 (국제대학교 e스포츠학과 주최)
- LoL 대학리그 중계팀 (2024)
- 국제대학교 방송국 기술팀장, 학과 방송 진행·운영

### QA 관련 경험
- Unity로 직접 기획·개발한 인디게임 2종의 테스트와 버그 수정
  - **JumpKing**: 점프킹 스타일 플랫폼 게임 (Windows 빌드)
  - **Amorupari**: 3D 3인칭 타임어택 게임 (Windows 빌드)
- 비공개 게임 알파 테스트 참여
- ISTQB CTFL v4.0 기반의 테스트 이론 학습

1. **Hero**: 이름, 게임 QA 테스터 지망, 연락처
