### 채워야 할 콘텐츠
가장 부족한 부분이며, 본인의 실제 자료로만 채웁니다. 경험하지 않은 테스트를 만들어 넣지 않습니다.

| 콘텐츠 | 상태 | 내용 |
|---|---|---|
| 인디게임 소개 (2종) | 일부 필요 | 이름과 엔진(Unity), 플랫폼(Windows)은 확인됨. 빌드 배포 링크, 스크린샷, 플레이 영상은 아직 없어 직접 촬영 필요 |
| 인디게임 버그 리포트 | 정보 필요 | 두 게임에서 실제로 발견하고 수정한 버그 게임당 2~3건. 증상, 재현 절차, 원인, 수정, 확인 |
| 테스트 케이스·계획서 | 작성 필요 | 두 게임 기준으로 기능·물리/충돌·조작감·UX 테스트 케이스 작성. Amorupari는 카메라, 타이머 정확도, 기록 저장도 포함 |
| 게임 분석 리포트 | 선택 | 즐겨 하는 게임(LoL, TFT, 이터널리턴 등)의 패치, 밸런스, UX 문제 분석 |
| 증빙 자료 | 정보 필요 | ISTQB 자격증 사본(개인정보 가림), 창업경진대회 상장, 대회 기획·중계 링크나 사진 |

기대 결과:
실제 결과:
재현율:
첨부: (스크린샷 또는 영상)

### 기술 정리 (개편 시 함께 처리)
- 이미지 최적화: `images/` PNG를 WebP로 변환하고 `loading="lazy"` 적용 (현재 약 10MB)
- `index.html`을 HTML, CSS, JS로 분리
- 사용하지 않는 Favicon 인라인 코드와 `window.location.reload(true)` 정리
- 다크모드 유지 여부는 별도로 결정
