## 개편 상태

게임 QA 중심 구조(소개, QA 작업, 인디게임, 게임 경력, 활동, 연락)로 개편했습니다.
아직 없는 자료는 `작성 중`, `빌드 공개 준비 중`으로 표시하고, 실제 자료가 준비되면 채웁니다: 버그 리포트, 테스트 케이스, 테스트 계획서, 게임 스크린샷, 빌드 링크, 캡스톤 요약.

### 디자인 원칙
흔히 "AI가 만든 것 같다"고 느껴지는 기본값을 피합니다.
- 이모지 아이콘, 가짜 UI(터미널·브라우저 창), 발광·그라디언트·블러 배경을 쓰지 않습니다.
- 섹션마다 영문 라벨·번호를 붙이거나, 모든 카드를 hover로 띄우거나, 스크롤마다 등장 효과를 넣지 않습니다.
- 같은 크기 카드를 나란히 늘어놓기보다 표와 목록으로 정보를 정리합니다.
- 제목은 명조(Noto Serif KR), 본문은 IBM Plex Sans KR, 날짜·상태는 IBM Plex Mono를 씁니다.
- 색은 종이색 배경, 먹색 글자, 강조색 하나(적갈색)만 씁니다.
- 장식 대신 실제 QA 문서의 형식으로 전문성을 보여 줍니다: 문서 정보 표, 번호가 매겨진 섹션, 심각도 기준표, 테스트 항목 ID(`JK-01`, `AP-01`).
- 상단의 "PDF로 저장"으로 A4 이력 문서처럼 인쇄할 수 있습니다(인쇄 전용 스타일 적용).
