# 박준서 - 게임 QA 포트폴리오

게임 QA 테스터 취업을 목표로 하는 박준서의 포트폴리오 사이트입니다.
현재는 게이머·웹 개발 중심의 사이트이며, 게임 QA 직무에 맞는 사이트로 개편하고 있습니다.

## 저장소 구성

빌드 과정이 없는 정적 사이트입니다.

```
portfolio/
├── index.html      # 페이지 구조와 콘텐츠
├── css/style.css   # 스타일 (라이트/다크 테마)
├── js/main.js      # 테마 전환, 모바일 메뉴, 이미지 자리 표시
├── profile.jpeg    # 프로필 사진
├── images/         # 스크린샷과 증빙 이미지 (필요한 목록은 images/README.md)
└── README.md
```

`index.html`을 브라우저로 열면 확인할 수 있습니다.

## 개편 상태

게임 QA 중심 구조(Hero, About, QA Work, Indie Games, Game Experience, Activities, Contact)로 개편했습니다.
아직 비어 있는 부분(`준비 중` 표시)은 실제 자료가 준비되면 채웁니다: 버그 리포트, 테스트 케이스, 테스트 계획서, 게임 스크린샷, 빌드 링크, 캡스톤 요약.
