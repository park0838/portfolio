게임 QA 테스터 지망

박준서

경쟁 게임을 7년 동안 깊게 플레이했고, Unity로 직접 만든 게임 두 개를 테스트하며 버그를 고쳐 왔습니다. ISTQB CTFL v4.0으로 테스트 이론을 정리했습니다. 개발팀이 바로 재현하고 고칠 수 있는 리포트를 쓰는 것이 목표입니다.

자격
ISTQB CTFL v4.0
학력
국제대학교 e스포츠과 졸업
수상
평택시 청년창업지원센터 창업경진대회 동상
언어
한국어, 일본어(게임 코칭 경험)

park083800@gmail.com GitHub

1QA 작업

직접 만든 게임을 대상으로 한 테스트 문서입니다. 작성이 끝나는 대로 여기에 올립니다.

  • 버그 리포트

    JumpKing과 Amorupari에서 발견하고 수정한 버그. 재현 절차, 기대/실제 결과, 원인과 수정 내용.

    작성 중

  • 테스트 케이스

    기능, 물리·충돌, 조작감, UX로 나눈 케이스와 실행 결과.

    작성 중

  • 테스트 계획서

    게임별 테스트 범위, 환경, 우선순위, 일정.

    작성 중

  • 비공개 게임 알파 테스트

    비공개 게임의 알파 테스트에 참여해 밸런스 등을 검증하고 피드백 리포트를 작성했습니다. 계약상 게임 이름과 상세 내용은 공개할 수 없고, 참여 증빙은 요청하시면 보여 드릴 수 있습니다.

    참여

  • 캡스톤 연구: 게임 내 비매너 행위가 플레이어 경험에 미치는 영향과 개선 전략

    틸트를 유발하는 게임 구조를 분석하고, 사후 처벌보다 사전 환경 설계로 대응하자고 제안한 연구입니다.

    완료

버그 리포트 양식

제목증상을 한 줄로 요약
환경기기, OS, 게임 버전(빌드)
심각도 / 우선순위플레이 진행에 미치는 영향과 수정 우선순위
재현 절차번호를 매긴 단계별 절차
기대 결과 / 실제 결과의도된 동작과 실제 동작의 차이
재현율N회 시도 중 M회 재현
첨부스크린샷, 재현 영상, 로그
원인 및 수정원인과 수정 방법, 수정 후 확인 결과

심각도 기준

리포트에 등급을 매길 때 쓰는 기준입니다. 예시는 이해를 돕기 위한 가상의 사례입니다.

등급기준예시
치명 Critical게임이 종료되거나 진행이 불가능함, 데이터 손실클리어 직전 크래시, 세이브 파일 손상
높음 Major핵심 기능이 잘못 동작하지만 우회할 수 있음특정 벽에서 캐릭터가 끼여 재시작해야 함
보통 Minor일부 기능 이상, 플레이 흐름에는 큰 영향 없음기록 표시가 한 프레임 늦게 갱신됨
낮음 Trivial외관상 문제, 오탈자UI 텍스트 줄바꿈 어긋남

2인디게임

Unity로 기획하고 만든 게임입니다. 만드는 동안 직접 테스트하면서 버그를 찾고 고쳤습니다.

JumpKing

Unity · Windows · 2D 플랫포머

점프킹 스타일의 플랫폼 게임을 따라 만든 프로젝트입니다.

테스트 항목
ID확인 내용분류
JK-01점프 거리와 높이가 매번 같은지물리
JK-02벽과 모서리에서 끼이거나 판정이 어긋나지 않는지충돌
JK-03낙하 구간과 체크포인트가 의도대로 동작하는지기능

빌드 공개 준비 중

Amorupari (아모르파티)

Unity · Windows · 3D 3인칭 타임어택

직접 기획한 3D 3인칭 타임어택 게임입니다.

테스트 항목
ID확인 내용분류
AP-01카메라 움직임과 조작감조작/UX
AP-02타이머 정확도와 기록 저장기능
AP-03지형에 끼이거나 맵 밖으로 나가지 않는지충돌

패치노트와 메타 변화를 따라가며 플레이했습니다.

게임최고 티어플레이전적

게임패드로는 테라리아, Green Hell, 철권, 스타듀밸리, 코어키퍼를 플레이했습니다.

4활동

  1. 2022

    하나원큐 ‘집에서 즐기는 롤 대회’ 8강

    전국 약 250개 팀 중 8강. 정글 포지션.

  2. 2023

    평택시 청년창업지원센터 창업경진대회 동상

    ‘AI를 활용한 정신건강상담치료 시스템’ 아이디어를 기획하고 발표했습니다.

  3. 2023

    평택시고등학교 제2회 최강자전 기획팀

    국제대학교 e스포츠학과 주최 대회의 기획에 참여했습니다.

  4. 2024

    평택시고등학교 제3회 최강자전 기획팀장

    대회 기획과 일정 관리, 경기 규정 작성, 돌발 상황 대응, 기획팀 의견 조율을 맡았습니다.

  5. 2024

    LoL 대학리그 중계팀

    경기를 실시간으로 분석하고 전달하는 중계에 참여했습니다.

  6. 2023–2025

    국제대학교 방송국 기술팀장

    OBS, 오디오 인터페이스, 스위처, 카메라를 세팅·운영하고, 장비 문제가 생기면 원인을 찾아 해결했습니다.

  7. 2023–

    일본어 게임 코칭

    일본어로 LoL, 이터널리턴, TFT의 메커니즘과 전략을 설명했습니다.
